# ตัวกลางพิมพ์บิล (เครื่องขายหน้าร้าน)

รันค้างไว้ที่เครื่องขาย → หน้าเว็บส่งบิลมาให้ → มันส่งเข้าเครื่องพิมพ์บิลโดยตรง

```
หน้าขาย (เว็บ) ──POST รูปบิล──> ตัวนี้ (127.0.0.1:9110) ──RAW──> POS58 Printer
```

**ข้อดีเทียบกับการตั้ง Chrome แบบ kiosk-printing:** ไม่ต้องตั้ง POS58 เป็นเครื่องพิมพ์หลัก
จึงไม่ลากใบ A4 ลงม้วนกระดาษ 48 มม. ไปด้วย — เครื่องพิมพ์หลักตั้งเป็น Brother ไว้เหมือนเดิม
เอกสาร A4 พิมพ์ปกติทุกอย่าง

---

## ติดตั้งครั้งเดียว

```bat
winget install -e --id Python.Python.3.12
```
ปิด cmd แล้วเปิดใหม่ (ให้ Windows รู้จักคำสั่ง python) จากนั้น:
```bat
pip install pywin32 pillow
```

## ทดสอบก่อนว่าเครื่องพิมพ์รับไหม

```bat
python test_print.py
```
มีกระดาษออกมาอ่านว่า `OFU TEST` = ใช้ทางนี้ได้

## รันตัวจริง

```bat
python agent.py
```
ระบุชื่อเครื่องพิมพ์เองได้ถ้าเดาผิด:
```bat
python agent.py --printer "POS58 Printer"
```

ตรวจว่ารันอยู่: เปิด <http://127.0.0.1:9110/ping>

## ให้เปิดเองตอนเปิดเครื่อง

1. กด `Win + R` พิมพ์ `shell:startup` แล้ว Enter
2. สร้างไฟล์ `พิมพ์บิล.bat` ในโฟลเดอร์นั้น เนื้อหา:
   ```bat
   @echo off
   cd /d "C:\ofu\pos-print-agent"
   python agent.py
   ```

## ตัวเลือกเพิ่มเติม

| ตัวเลือก | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `--printer` | ชื่อเครื่องพิมพ์ (ต้องตรงเป๊ะกับใน Windows) | เดาจากชื่อที่มี POS/58 |
| `--port` | พอร์ตที่ฟัง | 9110 |
| `--dots` | ความกว้างหัวพิมพ์เป็นจุด (58 มม. = 384) | 384 |
| `--cut` | สั่งตัดกระดาษท้ายบิล | ปิด |

## เวลามีปัญหา

| อาการ | สาเหตุที่เจอบ่อย |
|---|---|
| ไม่มีกระดาษออกเลย | ชื่อเครื่องพิมพ์ไม่ตรง — ดูรายชื่อที่ agent พิมพ์ตอนเริ่ม |
| ออกมาเป็นตัวขยะ | เครื่องไม่รับคำสั่งพิมพ์ภาพแบบ raster (พบน้อยมาก) |
| หน้าเว็บบอกว่าต่อไม่ได้ | หน้าต่าง agent ถูกปิด หรือ Chrome บล็อกการคุยกับเครื่องในบ้าน |
| บิลขาดครึ่งใบ | หน่วยความจำเครื่องพิมพ์ไม่พอ — ลดขนาดรูป/ความสูงแถบใน `image_to_escpos` |

> ผูกกับ `127.0.0.1` เท่านั้น เครื่องอื่นในวงแลนสั่งพิมพ์ผ่านตัวนี้ไม่ได้
